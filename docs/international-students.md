# 国际生模块需求 Spec（P4，初稿 2026-10-15）

> 来源：用户 2026-10-15 提出。目标：在中国的人，在线入学加州 CC，结合多样化身份背景做入学筛选指导、选课与可转课程评估、未来 CC 在读辅导。

## 一、目标人群

身在中国、希望通过"加州 CC（在线）→ 转 UC/CSU"路径的国际生。

## 二、四类身份画像（差异化指导）

| 画像 | 关键差异点 | 工具要给的 |
|---|---|---|
| 中国在读大学生（有大学课程成绩） | 已有课程可能转学分 | 课程可转性预评估：按目标校/WES 口径给"可能性"分级，列出需要准备的材料（课程描述/大纲翻译件） |
| 中国高中毕业生 | 标准路径 | 标准入学流程 + 语言要求（TOEFL/IELTS/Duolingo 各校门槛）+ 材料清单 |
| 16 岁以上（含低龄申请人） | 年龄门槛、监护要求 | 各 CC 的年龄政策、监护人/住宿相关要求提示 |
| Homeschool 自学生 | 无标准高中成绩单 | 替代性成绩证明指导（作品集、标准化考试、课程描述），各校接受度差异提示 |

## 三、功能模块

1. **入学筛选指导**：按画像 + 预算 + 目标 → 推荐匹配的 CC（筛选条件：收国际生、有 online 项目、学费、转学率），输出材料清单 checklist。
2. **选课与可转课程评估**：输入已有课程成绩 → 对照目标校 articulation/WES 评估口径 → 可转/存疑/不可转三级；明确标注"最终由学校或 WES 认定，工具只给可能性"。
3. **在读 CC 辅导**：复用 P1 的对比器/校验器/TAG Guard，按国际生时间线调整（申请季、身份维持相关节点）。

## 四、硬边界（必须遵守）

- **签证/移民只给公开信息，不做建议**：F-1 签证有 physical presence 要求，纯在线在中国读和拿 F-1 是两回事。各校 online international program 政策不同，需逐校核实。本工具不提供移民法律建议，有疑问咨询移民律师。
- **学分认定只给可能性**：中国大学课程能否转，没有统一规则，每所学校/WES 独立评估。工具输出必须带"可能性分级 + 免责"，绝不承诺"这门课一定能转"。
- 所有政策类内容标注来源 URL + 核验日期，与 TAG 规则同一标准。

## 五、前置研究（启动前要做的）

- 各试点 CC 的 international online program 现状（收不收、学费、语言门槛）
- WES/IERF 对中国课程的评估口径（公开文档）
- F-1 在线学习相关政策（仅整理公开信息）

## 六、排期

P4，P1 打磨 + P2（UC 在读规划器）之后。不提前铺摊子。
